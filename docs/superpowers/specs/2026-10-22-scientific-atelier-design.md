# 命运石之门主题系统：Scientific Atelier 视觉语言与设计规范

> 文档状态：根据项目负责人最新澄清修订中。Scientific Atelier 是命运石之门主题系统的核心视觉语言，不是独立主题；书面规范待审阅，Figma 文件尚未创建。
> 日期：2026-10-22
> 适用范围：北航粒子物理课题组对外学术官网；不包含内部 /hub 协作工作区。
> 参考基准：本任务中用户提供的粒子物理研究组首页概念图。该图是首要视觉参考，不是可直接照搬的品牌或科学数据来源。

## 1. 目标与设计决策

### 1.1 目标

将 **Scientific Atelier（科学绘图室）** 定义为现有 **命运石之门（Steins;Gate）主题系统的核心视觉语言**，而不是一套独立主题。以用户提供的暖白纸张、精密工程网格、手绘机械与物理线稿、公式标注和优雅衬线标题为基础，同时融入《命运石之门》的蓝黑色电子终端、荧光终端绿、复古实验室设备、手机邮件界面和科学悬疑气质。粒子碰撞、轨迹绘制、刻度偏移和图层变化属于同一主题的交互动效。

网站应像一份精心制作的现代物理研究档案，而不是通用科幻驾驶舱或营销落地页。研究内容、论文、公式与资源的可读性始终高于装饰。

### 1.2 已确认决策

- 用户提供的首页概念图是首要视觉基准。
- 直接扩展现有 `worldline-console`（当前公开名称为“世界线蓝图”）主题，不新增主题 ID 或独立的 “Scientific Atelier” 选项。Scientific Atelier 是命运石之门主题内部的视觉语法：纸张、网格、科学线稿和编辑式排版与蓝黑终端、终端绿、复古设备和实验室叙事共同组成一个连贯系统。
- 动效级别为“丰富演出”：允许粒子碰撞、轨迹动画、扩散波、刻度偏移、短暂故障切片和图层变化；动画必须有意义、可停止、可访问。主题切换时只播放视觉特效，不显示“世界线变动”等叙事文字、提示或横幅。
- 首期面向公众的页面包括首页、研究专题、团队与学术指导、公开学术活动。
- 首页内的代表论文与物理资源区属于首页内容模块；当前 /resources 路由是登录后的内部资料整合功能，不得误当作公开资源页。
- 内部 /hub、登录后文献库、组会、邮箱、学习与计算、个人账户和管理页面均不在本次 Figma 设计范围内。
- 不新增“设施”“外联”“加入我们”等独立页面，除非未来单独批准；参考图中的导航结构只用于视觉启发。
- 设计文件只负责设计资产和界面规范，不直接修改生产代码、数据库、Cloudflare 配置或部署。

### 1.3 品牌和内容真实性

- 品牌视觉可使用“引力之外”及英文说明语 *Exploring Physics Beyond the Standard Model*，并与正在进行的品牌身份工作保持一致。
- “引力之外”是视觉与精神品牌，不自动替代正式机构名称。公开内容继续使用网站白名单中的确认信息；“北航粒子物理研究组”当前仍为暂定名称时，必须保留相应提示。
- 首页的碰撞与探测器主视觉若为概念插画，须以可见图注或辅助文本标明“概念示意 / Conceptual illustration”，不得伪装成真实实验事件、数据或观测图。
- 论文、人员、机构、成果和联系方式不得由设计稿虚构；Figma 占位内容必须明确标记为占位符。
- 标志使用原创粒子轨道符号，不复制其他项目 Logo、影视游戏素材或参考图中的专有标识。“1/6”如被使用，只能作为克制的品牌叙事细节，不是物理参数或科学结论。

## 2. 视觉原则

### 2.1 画布与科学线稿

- 研究内容的主要承载面采用暖白/浅灰纸面，配低对比度、极细的工程网格；终端面板、旧式设备和特定主视觉区域使用蓝黑底与终端绿。两者通过同一套间距、线条、排版和动效令牌统一，不作为两个独立主题切换。
- 线稿素材可包含机械齿轮、轨道、圆规构造、探测器层、坐标轴、测量刻度、公式标注与示意曲线。
- 网格、齿轮、公式注释和装饰轨迹应作为可独立控制的图层，透明度低，不得干扰正文、交互控件或公式阅读。
- 线稿常规笔画建议为 0.5–1.25 px；主要结构线可略粗。装饰图层通常使用约 8–22% 视觉强度，最终以真实视口中的可读性为准。
- 不使用大面积玻璃模糊、强烈霓虹渐变、随机数字雨、无意义扫描故障或全屏高亮粒子作为常态背景。终端绿用于有明确设备/信息层级的局部，不把整站做成通用科幻驾驶舱。

### 2.2 首页主视觉构图

- 桌面首屏采用编辑式双栏构图：左侧为品牌眉题、主标题、简洁研究介绍与主要入口；右侧为探测器/粒子碰撞概念主视觉。
- 背景图纸和科学线稿可以跨越两栏，但必须在标题和正文背后降低对比度；主视觉应有明确焦点与足够留白。
- 主标题使用大号衬线字体，分行节奏清楚。英文小型大写眉题、编号与仪器标注可用适度字距。
- 主要 CTA 采用深海军蓝实心按钮；次级 CTA 采用透明或纸面背景与细线/箭头。
- 底部可用细线串联研究方向或页面锚点，但不得把信息密集度做成难以扫描的仪表盘。
- 手机端改为单列：品牌与标题优先，研究介绍和 CTA 随后，主视觉移至标题之后或按屏幕高度裁切；不得缩小正文来强行保留桌面构图。

### 2.3 页面气质

- 学术编辑感：明确层级、细分隔线、充分留白、内容优先。
- 工程绘图感：精细标注、圆弧、坐标和图层结构。
- 科学叙事感：动画展示“发生了什么”，而不是持续发光。
- 克制的戏剧性：碰撞中心、关键 CTA 和章节转场可以形成视觉焦点，普通阅读区域保持安静。

- 首页与主要内页使用 12 列响应式网格；桌面列间距建议 20–28 px。首页 Hero 可采用约 5/7 或 6/6 的灵活双栏，不固定裁切主视觉。
- 导航高度建议 72–84 px，使用纸面背景和细底边；避免强毛玻璃和过厚阴影。

## 4. 动效规范：丰富演出，安静阅读

### 4.1 动效原则

动效以“可解释的科学现象”为核心：粒子产生、轨迹弯曲、碰撞、扩散波、刻度偏移和图层显现。动画应在用户操作或首次进入主视觉时触发，不持续抢夺注意力，也不能阻塞阅读或导航。

### 4.2 动效清单

| 动效 | 触发方式 | 建议时长 | 规范 |
|---|---|---:|---|
| 科学线稿绘制 | 首页首屏进入或局部进入视口 | 600–1200 ms | 沿路径绘制，错峰出现；只在必要时播放一次 |
| 粒子轨迹 | Hero 首次展示、用户交互或指定章节进入 | 900–1600 ms | 轨迹弯曲、拖尾短而清晰；不遮挡标题和正文 |
| 碰撞与扩散波 | 用户主动点击指定视觉交互 | 1400–1900 ms | 中心闪光、环形波、粒子向外发散、短暂图层偏移；结束后回到稳定画面 |
| 刻度/相位偏移特效 | 章节跳转或主题切换 | 500–900 ms | 使用细线位移、局部色差、扩散波或刻度变化；纯视觉表现，不出现“世界线变动”文字，不模拟持续故障 |
| 章节进入 | 滚动进入视口 | 350–650 ms | 轻微透明度与位移组合，按组错峰 40–80 ms |
| 卡片/按钮悬停 | hover / focus / active | 160–240 ms | 细线增强、下划线或箭头位移约 3–5 px；不使用 3D 倾斜 |
| 页面/锚点导航 | 用户导航 | 180–320 ms | 平滑且快速；尊重减少动态效果设置 |

### 4.3 性能与可访问性约束

- 大范围粒子画布只用于首页 Hero 或明确的专题主视觉，不作为所有页面的常驻全屏背景。
- 画布/动画按路由和可见性按需启动；页面离开、标签页隐藏或主视觉离开视口时暂停不必要的动画。
- 控制粒子数量、像素比和绘制频率；移动设备使用更低密度，避免高成本 WebGL 或 Canvas 动画阻碍滚动。
- 动画不得造成布局跳动，不应将主要内容延迟到动画完成后才可读或可操作。
- 必须尊重 prefers-reduced-motion：关闭持续粒子循环、视差、爆发与路径绘制；以静态线稿或轻微透明度变化替代。
- 闪光不能高频、全屏或高对比闪烁；交互状态必须同时具有非颜色信号。
- 不允许自动播放声音、闪屏、持续摇晃或无意义随机故障。

## 5. 组件清单与状态要求

Figma 中应先创建基础变量和样式，再构建组件。组件的填充、边框、间距与圆角默认绑定对应变量。

1. **Brand Mark / Wordmark**：原创粒子轨道符号、中文品牌名、学术方向说明、英文说明语；含横版与窄屏变体。
2. **Public Header / Navigation**：桌面导航、移动菜单、当前项、焦点、展开/关闭状态；使用当前真实公开路由和首页锚点。
3. **Primary / Secondary / Text Button**：默认、hover、focus、pressed、disabled 状态；主要按钮最小触控高度 44 px。
4. **Eyebrow / Section Heading**：章节编号、英文眉题、标题、辅助说明和分隔线组合。
5. **Scientific Illustration Layer**：网格、轨道、机械线稿、公式注释、碰撞主视觉；装饰层与内容层分离。
6. **Research Direction Card / Tab**：研究方向名称、简介、符号、选中状态与相关内容入口；不依赖颜色单独表达选中。
7. **Publication Row / Publication Card**：标题、作者、期刊/年份、arXiv/DOI、引用复制或 BibTeX 操作；长标题和 DOI 可折行。
8. **Public Resource Card**：资源名称、类别、说明、外链状态；不显示登录后内部资源。
9. **Person Card**：姓名、已确认职务/单位、研究方向、官方来源链接；不得要求未获许可的照片或个人信息。
10. **Event Card / Timeline Item**：公开学术活动的时间、标题、报告人和详情入口；只展示已批准公开信息。
11. **Sidebar / Section TOC**：长页面目录、当前章节和键盘状态；手机端转换为可展开目录。
12. **Breadcrumb / Footer / Metadata**：内页导航、机构信息、版权与来源说明。
13. **Motion States**：线稿未绘制/绘制中/完成、粒子静止/运动/碰撞/衰减、主题切换的纯视觉过渡、Reduced Motion 替代状态。

组件需记录用途、状态和可访问性说明。不要为每个图标创建独立变体；图标应使用可替换的实例属性或语义图标组件。

## 7. Figma 设计系统组织与验收

### 7.1 变量与样式

- 建立原语色彩、语义色彩、间距/圆角和动效时长等变量组。
- 语义变量引用原语变量，不重复硬编码颜色。
- 创建展示标题、页面标题、章节标题、正文、UI、元数据与等宽标注等文本样式。
- 对常用组件的填充、边框、间距、圆角和状态使用变量绑定。
- 组件名、属性和变体应稳定、可检索；避免过大的笛卡尔积变体矩阵。

### 7.2 验收标准

- Figma 文件有明确的页面结构、封面、设计原则和来源说明。
- 基础色彩、字体、间距、圆角、线条和动效令牌齐全，命名一致且语义变量正确引用原语。
- Header、按钮、研究卡片、论文条目、资源卡片、人员卡片、活动条目、目录与页脚具备必要状态。
- 首页桌面和手机版本均完成；研究专题、团队与学术活动页面有可复用模板。
- 参考图被放入文件作为视觉参照，但不被误认为已批准的正式品牌资产或科学数据。
- 所有装饰线稿与科学示意均可与正文分层；概念碰撞图有清晰说明。
- 在 1440、1024、768、390 和 320 px 视口下检查层级、换行、导航、横向溢出与可读性。
- Reduced Motion 状态有明确的静态替代方案。
- 在 Figma 中验证变量、字体、组件变体和关键画面；发现裁切、低对比、空白组件或脱离布局的元素时先修复再交付。

### 7.3 代码集成与依赖风险

当前主分支已有 `worldline-console` 主题（公开名称“世界线蓝图”）、共享语义变量、PublicThemeSwitcher 和 WorldlineEffects。Scientific Atelier 不另建主题，不新增主题 ID 或切换入口；设计工作应整合到现有 `worldline-console` 的组件与令牌中。主题切换的世界线风格演出只呈现动画，不显示“世界线变动”等字样。多个开放 PR 也涉及主题与动效共享热点，以及“引力之外”品牌文件。

因此本规范阶段只新增设计文档，不修改这些共享代码。用户审阅并批准本规范后，才创建 Figma Design 文件。将来若把设计应用到代码，必须重新读取最新 main、检查所有开放 PR 的 HEAD 与 changed-files，并协调 design.md、frontend/src/index.css、PublicThemeSwitcher.vue、WorldlineEffects.vue、useThemeStyle.js 等共享文件的所有权；不得覆盖其他开发会话的工作。

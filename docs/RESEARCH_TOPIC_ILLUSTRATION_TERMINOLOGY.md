# 五个研究专题插图：文字与物理术语核对清单

**状态：** PR #20 的插图校对基线。此文档定义文字与图意边界；不代表专题正文或任何物理计算已通过独立复现。

## 总则

1. **文字不交给图像生成模型绘制。** 所有可见文字均直接写入 SVG 的 `<text>` / `<tspan>`，以便检查拼写、希腊字母和下标。
2. **可见文字采用白名单。** `frontend/scripts/topic-illustration-terms.json` 是自动化检查使用的机器可读基准；新增标签必须先更新清单、再审查物理含义。
3. **没有数据就不画成数据。** 五张图中的曲线、网格、颜色和探测器形状均为概念构图，不是实验事件显示、数值求解、拟合结果或定量预测。页面图注也会说明这一点。
4. **不在插图里放未经核查的复杂公式。** 当前只保留中微子图中必要的态标记、混合矩阵标记和 (L/E)，以及量子计量图中用于示意坐标的 (x,y,z,\theta)。不在图中声称某个具体参数点、概率、频谱或 Fisher 信息数值。
5. **符号约定：** 中微子味态写作 \\(\\nu_e,\\nu_\\mu,\\nu_\\tau\\)，质量本征态写作 \\(\\nu_1,\\nu_2,\\nu_3\\)，PMNS 矩阵写作 \\(U_{\\mathrm{PMNS}}\\)。在 SVG 中用 `<tspan baseline-shift="sub">` 表示下标，不能把下标依赖字体猜测或拼成普通基线字符。

## 自动化验收

- `frontend/scripts/check-topic-illustrations.mjs` 使用 Python 标准库的 XML 解析器检查 SVG 是否为良构 XML。
- 校验每张 SVG 的 `title`、`desc`、可见文字、下标标记、唯一 ID 和 `aria-labelledby`。
- 校验专题页面的 `alt` 文本与此清单一致。
- `npm test` 与 `npm run build` 均会执行插图检查；浏览器烟测另外检查实际加载。
- 若物理图意发生变化，必须同时更新 SVG、机器可读清单、此文档及测试，不能只改其中一项。

## 物理范围说明

这些插图用于帮助读者识别研究对象，不是教材级的完整物理图，也不替代公式推导。特别是中微子图中的矩阵色块没有数值含义；相变图没有指定模型参数；暗物质图没有采用某个实验的能量响应；量子计量图没有给出量子态、测量算符或 Fisher 信息的计算定义。正式科研结论必须回到正文中的明确定义、数据来源与可复现计算。

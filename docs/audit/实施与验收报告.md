# 网站改进与验收报告

日期：2026-10-20。依据用户提供的 `design.md` 和《BUAA HEP Hub 网站审计与物理内容完善方案》，按权限/Token、性能、确认后公开内容、SEO 与体验的顺序实施。

## 已落实

| 编号 | 改动与验收证据 |
|---|---|
| SEC-01 / SEC-06 | 资料编辑和删除统一为创建者或管理员；教师不获得全局资料修改权，无创建者的种子资料仅管理员可改。D1、FastAPI 与演示适配器规则一致，UI 保持同一能力。HTTP 权限矩阵覆盖创建者、其他成员、管理员、教师和授权组会成员。 |
| SEC-02 | SSE 复用通用 Bearer 认证及数据库 token_version 校验；所有通用 API 和 SSE 拒绝 URL 查询参数中的 JWT。前端原本已使用 fetch + Authorization，因此无需另造 URL 票据。改密后旧 JWT 在普通 API 和同步接口均返回 401，新 JWT 可用。 |
| SEC-03 | 所有 D1 组会端点使用同一 canManageSeminars 函数；去除错误字段 is_seminar_manager。主讲账号优先于姓名；未绑定旧记录仅允许唯一精确姓名匹配，重名不能冒用；主讲人不能越权重新排期或改派账号。 |
| SEC-04 | D1/SQLite 持久化、原子计数：登录每账号 10 次/15 分钟，每 IP 60 次/15 分钟；凭据修改每账号 10 次/15 分钟，注册按 IP 限速。返回 429 与 Retry-After。计数包含失败及成功尝试；到期自动重置。数据库键保存散列标识，不记录明文邮箱/IP/密码/JWT。新密码至少 8 字符，最多 72 UTF-8 字节；原有短密码仍可登录。 |
| SEC-05 | 去除认证默认签名密钥，配置缺失/过短时拒绝认证。修复改密新 JWT 漏 token_version 的问题；拒绝缺失有效期/版本或签名不符的令牌。FastAPI 直接启动需配置强 LABHUB_SECRET_KEY；serve-local.py 保留本地随机密钥文件机制。 |
| CI-01 | GitHub Pages 演示不再随主分支推送自动发布，改为手动且需 ENABLE_GITHUB_PAGES_DEMO=true。Cloudflare 发布流程明确区分验证与发布；未配置 Secrets 时写清“未发布”，不声称部署成功。 |
| CI-02 | CI 串行门槛：前端/API 测试、本地后端回归、生产构建、入口预算、浏览器检查、本地 Pages 运行时检查，然后才允许部署；发布后执行只读健康与匿名授权检查。 |
| PERF-01 | /hub 路由与工作台外壳组件异步加载；公开页不读取内部 API、不下载隐藏云景、PDF.js 或 WebGL。GSAP、KaTeX 标题排版、TIFF 解码、PDF 解析按需加载。主页/工作台分别执行 gzip 初始 JS ≤250000 字节的构建门槛。 |
| CONTENT-01 | 用户已确认全部 16 篇、6 类和 5 个方向。13 篇期刊论文、3 篇预印本分别标记，保留完整作者、DOI/期刊、来源、日期和分类；研究介绍区分模型预言、探测灵敏度和实际观测。 |
| UX-01 | 论文支持主题、年份、排序、编号/DOI/作者/期刊/主题搜索、复制引用与 BibTeX；方向可跳到相关论文。增加 Home/End 键并同步焦点；手机表单、菜单与 DOI 可折行。 |
| SEO-01 | 公开页构建时静态预渲染，关闭 JS 仍可读；canonical、Open Graph、Twitter 摘要卡、课题组与论文 JSON-LD、robots 和 sitemap。内部路由有 noindex；该设置不替代服务端权限检查。 |

## 实际运行验证

- 前端/API：102 个测试文件，738 项通过（原基线 99 个文件、702 项）。安全测试通过真实 SQLite 执行 SQL，并调用实际 Hono 路由，不以源码字符串判断代替权限测试。
- Cloudflare：本地 workerd/Miniflare + 独立临时 D1、无 R2，80 项运行时检查通过；不访问生产数据库、不创建生产测试账号。
- FastAPI：隔离内存数据库，安全回归、可选姓名注册与初始化共 14 项通过。
- 真实 Chromium 浏览器：37 项检查通过；320、360、390、768、1024、1440 px；公开页与工作台、日程、资料、文献库、账户页面；键盘、无结果、年份/DOI 检索、引用导出、方向互链、关闭 JS 与未登录重定向。
- 生产构建、演示构建与公开/工作台初始 JS 预算检查通过。构建仍提示未加载的 Three.js 独立包大于 500 KB，此包只在用户选择相应功能时下载。

## 同条件性能对比

每个入口独立冷启动 3 次，下表取中位数。Chromium，390×844 CSS px，CPU 4 倍降速，150 ms 延迟，200000 字节/秒下载；同一台电脑的无压缩本地静态服务器。JS 体积是实际初始请求中 JS 文件逐个 gzip 后求和；这是可重复的构建/实验室对比，不是线上 CDN 传输量或真实用户分位数。

| 入口 | 初始 JS（gzip，十进制 KB） | LCP 中位数 | 初始资源请求数 |
|---|---|---|---|
| 公开首页 | 615.60 KB → 82.43 KB | 13.608 s → 1.956 s | 5 → 5 |
| 工作台（隔离演示数据） | 609.95 KB → 245.88 KB | 13.528 s → 6.512 s | 5 → 63 |

拆包增加了资源数量，同时明显降低初始代码量；公开页也移除了不显示的背景下载。当前目录包含更多已确认论文，仍满足初始 250 KB 预算。

交互采用 PerformanceEventTiming 记录真实浏览器的自动化点击；优化后公开页记录约 24 ms，工作台约 16–32 ms。未观察到条目不等于 0 ms。该数据是实验室交互时延，不宣称为真实用户 INP；真实 INP 分位数需要上线后的实际使用样本，本轮没有添加访客跟踪。

原始数据：`performance-before.json` 与 `performance-after.json`；复测命令：`node frontend/tests/measure-performance.mjs after`。布局截图由真实浏览器生成，副本保存在本次交付目录。

## 内容与隐私边界

- 公开页面只读取 `frontend/src/content/lab.js` 白名单；没有从内部日程、成员表、通知、邮箱或生产数据库生成公开内容。
- 保留“暂定名称”；不新增照片、办公地址、联系方式、履历、项目、未发表内部材料。
- 16 篇论文核对了原始 arXiv 和 INSPIRE 元数据；没有声称独立复现各论文的计算。后续长专题、公式推导和复现资料按 `docs/research-content-template.md` 审核，不生成无依据的“已验证”结果。

## 仍需持续维护的事项

- 仓库尚无专用 Cloudflare API Token/Account ID Secrets，GitHub 自动发布未启用；当前可使用已授权的本机 Wrangler 发布。不要把本机 OAuth 令牌复制成仓库的长期发布密钥。GitHub Actions 页面显示的验证成功不等于已发布。
- bcrypt 成本保持原有 6，没有未经 Worker CPU 预算验证就盲目调高；后续可在部署环境采集 CPU 指标后评估提高成本。当前新增了新密码长度/字节上限及分布式失败保护。
- 未进行完整渗透测试、所有浏览器/定制主题测试、原生浏览器 200% 缩放验收或真实用户 INP 统计；不要把所列回归检查称为全面安全认证。
- 论文元数据建议 3–6 个月人工核对一次，维护人待课题组指定；发布状态、DOI 和勘误更新后需经过人工审核。

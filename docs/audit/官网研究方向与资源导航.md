# 对外官网：研究方向与物理资源

日期：2026-10-21。用户明确要求继续完善无需登录的官网，补充研究方向说明和外部物理网站导航。本轮未将组内学习初稿转为公开成果。

## 内容

- 保留已批准的五个方向，为每项增加研究问题、主要方法、实验联系、适用范围和两篇已批准论文的原始链接。论文清单仍为 16 篇、6 类；未增加新成员、内部日程或未发表材料。
- 新增“物理资源”导航与公开资源区，共九项：PDG、INSPIRE-HEP、arXiv hep-ph、HEPData、CERN Open Data、FeynCalc、MadGraph5_aMC@NLO、ROOT、REANA。提供用途说明及文献/数据/计算分类，不加入第三方脚本、嵌入或追踪。
- 桌面三列、窄屏一列，900px 以下收纳官网导航，兼顾平板宽度。保留键盘方向切换、相关论文筛选、减少动态偏好与安全外链属性。
- 关闭 JavaScript 时提供五个方向的静态全文，并保留九个外链；预渲染继续只读取公开白名单，不调用组内 API。

## 来源与范围

研究说明依据既有确认论文，重点核对 arXiv:2603.17237、2110.14665、2409.17243、2210.09335、2111.01164、2508.13276、2505.06001、2506.10673、2610.04971 的原始记录。方向内的选读链接不表示对所有论文进行了独立计算复现；不新增实验排除数值或未经确认的未来观测结论。

资源用途依据各项目/机构的官方主页。HEPData 对自动正文读取返回 403，但 PDG 官方资源索引列出这一入口；INSPIRE 首页需要 JavaScript。未把这些情况称为完整的外部浏览器可达性验证。CERN Higgs 工作组的旧 TWiki 入口本次未呈现有效正文，因此没有加入导航。

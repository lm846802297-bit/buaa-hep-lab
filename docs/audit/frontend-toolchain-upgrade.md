# Frontend Toolchain Upgrade — Staged Verification

## Scope

This change is isolated on `upgrade/frontend-toolchain-vite8-vitest5-tailwind4` and is intended to be reviewed separately from the semver-compatible dependency remediation.

Direct toolchain versions:

- Vite: `8.3.5`
- `@vitejs/plugin-vue`: `6.0.10`
- Vitest: `5.0.5`
- Tailwind CSS: `4.3.3`
- `@tailwindcss/vite`: `4.3.3`

Vite 8 uses Rolldown/Oxc rather than the previous Rollup/esbuild toolchain. The project keeps its explicit build target (`es2020`, `safari14`) rather than relying on Vite's changing default target.

## Changes

1. Upgrade Vite, its Vue plugin, and Vitest.
2. Migrate Tailwind CSS v3 to v4:
   - replace the legacy `@tailwind base/components/utilities` directives with `@import "tailwindcss"`;
   - load the existing `tailwind.config.js` with `@config "../tailwind.config.js"` to preserve the custom serif font and brand colors during the transition;
   - use the dedicated `@tailwindcss/vite` plugin;
   - remove Tailwind CSS itself from the PostCSS plugin list. The existing Autoprefixer PostCSS step is retained for now.
3. Update the local-background storage test mock so `global.URL` remains a constructor. The old mock replaced it with a plain object, which fails when Vitest 5's resolver or dependencies use `new URL()`.
4. Update the lockfile only after a clean install, the frontend test suite, production build, and demo build pass.

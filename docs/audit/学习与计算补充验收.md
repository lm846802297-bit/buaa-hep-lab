# 学习与计算补充验收

日期：2026-10-20。继续落实两份文档中 P1 的基础物理学习内容、来源追踪、公式可访问性与复现记录。公开首页仍使用已经批准的 16 篇论文、6 类和 5 个方向。

## 本轮交付

- `/learning/:topic?`：工作台和资料库均有入口；进入时沿用现有登录与演示机制，未知专题提供恢复入口。内部路由保持 noindex。
- 五个学习初稿：标准模型与电弱破缺；振幅、截面与衰变；BSM 一致性；SMEFT 与 UV–EFT；FeynCalc 与可复现计算。
- 每篇提供前置知识、学习目标、分节参考、核心公式、LaTeX 源码、适用条件、自查题、版本和审核状态。公式仅在学习页加载 KaTeX，保留 MathML 与源码回退。
- 十一项权威资源，可按正文关键词和类别筛选；保留本节来源，导出 Markdown 笔记与复现模板。未查到或未能读取的来源不假称正文核验通过；HEPData 正文读取受限，INSPIRE 为需浏览器交互的索引入口。
- 可下载的 Python 两体衰变基准：不同实标量、树级、自然单位，g 为有质量维数的三标量耦合；16 项运动学、量纲和数值一致性检查。输入 M=10、m1=1、m2=3、g=1（GeV），输出宽度 0.0017865098053841293 GeV；相对容差 1e-10、绝对容差 1e-14。

## 实际验证

- Vitest：103 个文件、747 项全部通过。新增测试覆盖学习资料检索、全部专题的真实服务端渲染、KaTeX 可解析性、MathML、未知链接、导出与来源引用。
- Chromium 本地构建：62 项检查通过，保留既有官网/工作台检查，并增加 320、390、768、1440 px 的学习页布局、各专题公式溢出与源码展开、键盘切换与标题焦点、正文/模板/脚本下载、资源筛选、空状态、深链接和未登录重定向。
- Python 标准库基准：16 项通过。独立求动量使用能量守恒方程二分求根，再积分角分布；不重复使用解析动量表达式。该检查支持教学实现的一致性，不代表复现真实研究论文。
- 生产与 Demo 构建通过；初始 gzip JS：公开页约 82.5 KB，工作台约 246.1 KB，均低于 250000 字节预算。学习正文和公式排版按需下载，不加入官网入口。
- 本地 workerd/Miniflare 与隔离 D1：80 项运行时回归通过，没有读取/改写生产数据库，没有启用 R2。
- FastAPI 隔离数据库回归：15 项通过，覆盖安全、可选姓名注册与首次初始化。
- Git 差异检查按仓库现有 CRLF 约定执行；本轮不更换依赖、不修改密钥、不迁移数据库。

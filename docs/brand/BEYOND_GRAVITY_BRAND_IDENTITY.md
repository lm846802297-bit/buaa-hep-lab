# 「引力之外」品牌身份与使用规范

> 状态：品牌提案已获项目负责人认可；这不是课题组正式更名、商标注册或学校机构命名文件。

## 1. 品牌分层

- **视觉与精神品牌：**「引力之外」。
- **学术方向说明：**「高能理论与粒子唯象研究」。
- **英文说明语：** *Exploring Physics Beyond the Standard Model*。
- **正式机构身份：** 继续使用网站当前确认状态下的机构与课题组信息。现有「北航粒子物理研究组」仍标记为暂定名称，不因品牌上线而自动变成正式名称。
- **品牌的作用：** 传达探索标准模型之外物理的方向感；学术说明仍负责让同行、学生和公众快速识别研究领域。

## 2. 视觉原则

1. 使用原创的粒子轨道符号，不复制任何歌曲封面、角色形象、PV 截图或歌词。
2. 将「1/6」作为克制的视觉彩蛋，呼应月球重力与“让沉重之物变轻”的灵感；它是品牌叙事符号，不是课题组的科学结论或参数。
3. 默认官网继续使用 Quiet Research 的纸白、墨色与克制强调色。标志颜色通过 `--accent`、`--text`、`--line` 等语义变量适配主题，不另建一套全局配色。
4. 不让品牌动画盖过论文、公式、专题导读和研究说明；所有动效尊重 `prefers-reduced-motion`。
5. 不把「引力之外」写成已经获批的正式课题组名称，也不擅自改动人员、单位、职务等公开学术信息。

## 3. 页面使用规则

- 官网首页左上角显示「引力之外」字标，副标明确写出「高能理论与粒子唯象研究」。
- 首页英文眉题使用 *Exploring Physics Beyond the Standard Model*；现有研究介绍和五个研究方向内容保持不变。
- 团队页与公开学术活动页的面包屑和浏览器标题使用「引力之外」。
- 首页的机构归属与现有课题组名称仍由当前学术内容白名单提供，并保留“暂定”提示。
- 浏览器图标采用原创轨道符号与「1/6」元素，不再显示参考项目的 LabOrbit 图形。

## 4. 本次变更范围与未完成项

本次品牌分支只调整品牌配置、首页字标、团队/活动页的品牌引用和浏览器图标；不改动认证、API、数据库、生产配置、研究内容、实验数据或组内工作台主题偏好。

研究专题详情页的面包屑与页面标题暂不在本分支修改，因为该文件正由独立专题内容开发分支维护。静态 HTML 的 Open Graph/Twitter 标题和描述也暂不修改，因为 `frontend/index.html` 正由主题兼容性分支维护。待这些共享文件的并行开发边界解除后，再单独补齐，避免覆盖其他分支的工作。

## 5. 验收标准

- 首页可见「引力之外」、学术方向说明和英文说明语。
- 「1/6」只作为装饰性标记；不会取代正式机构信息。
- 课题组名称仍保留暂定状态。
- 团队与公开学术活动页的面包屑和浏览器标题使用新品牌。
- 主题颜色通过语义变量继承，窄屏下字标可换行且不引发横向溢出。
- 单元测试与构建由本分支对应 SHA 的 CI 结果确认；未通过前不合并、不部署。

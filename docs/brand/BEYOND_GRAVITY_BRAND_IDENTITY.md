# 「引力之外」品牌身份与使用规范

> 状态：品牌提案已获项目负责人认可；本文件定义网站品牌，不构成课题组正式更名、商标注册或学校机构命名。

## 1. 品牌分层

- **视觉与精神品牌：**「引力之外」。
- **学术方向说明：**「高能理论与粒子唯象研究」。
- **英文说明语：** *Exploring Physics Beyond the Standard Model*。
- **正式机构身份：** 继续使用经核实的学校、学院与课题组信息。现有课题组名称仍按内容数据中的“暂定”状态呈现，不因品牌上线自动成为正式名称。
- **品牌定位：** 以可检验的新物理为学术主线，以“引力之外”表达探索既有理论边界的愿景。

## 2. 视觉原则

1. 使用原创粒子轨道符号，不复制初音未来形象、歌曲封面、PV 截图或歌词。
2. 将 **1/6** 作为克制的视觉彩蛋，呼应歌曲灵感中的月球重力与“让沉重之物变轻”；它是品牌叙事符号，不是课题组的物理参数或科学结论。
3. 让标志通过 `--accent`、`--text`、`--muted`、`--wl-ink` 等现有语义变量适配 Quiet Research、Worldline Console 与其他主题，不另建全局调色板。
4. 品牌不应盖过论文、公式、专题导读和研究说明。动效必须尊重 `prefers-reduced-motion`。
5. 不把「引力之外」写成已获批准的正式课题组名称，也不擅自更改人员、单位、职务或公开学术信息。

## 3. 页面使用规则

- 五种首页主题共享同一个品牌字标，确保主题切换时名称、学术副标和 `1/6` 标记一致。
- 首页品牌显示「引力之外」，副标显示「高能理论与粒子唯象研究」；英文眉题显示 *Exploring Physics Beyond the Standard Model*。
- 研究专题、团队与公开学术活动页面的页面标题和首页导航采用「引力之外」。
- HTML title、description、Open Graph 与 Twitter metadata 在原始模板和预渲染产物中保持一致。
- JSON-LD 中的机构名称仍使用现有课题组名称与其暂定状态，不把品牌误写成法定或正式机构名。
- 浏览器图标采用原创轨道符号和 `1/6` 元素。保留现有图标 URL，避免破坏部署路径。

## 4. 本次变更范围

本分支在最新 `main` 基线上统一五种首页主题的品牌字标，更新公共页面标题、研究专题导航、社交分享元数据、预渲染逻辑、图标与回归测试。不修改认证、API、数据库、生产配置、人员资料、研究内容或组内工作台的主题偏好。

## 5. 验收标准

- 五种首页主题均显示同一品牌与学术方向副标；默认 Worldline 主题及窄屏布局不发生横向溢出。
- 英文说明语在首页可见。
- 研究专题、团队、活动页的动态标题与静态预渲染标题均带品牌名称。
- 首页与公开子页面的 Open Graph / Twitter 标题与 HTML title 一致。
- 「1/6」只作为装饰性品牌标记；正式课题组名称继续保留暂定状态。
- 前端单元测试、构建、预渲染、浏览器烟测及隔离运行时检查通过后再进行人工审查；本分支不自动合并、不部署生产。

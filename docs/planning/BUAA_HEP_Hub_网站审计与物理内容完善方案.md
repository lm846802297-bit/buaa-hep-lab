# 第一部分：网站结构与工程改进

## 1. 建议的主导航

建议将网站组织为以下一级栏目。它们是推荐的目标架构，不代表现有网站一定缺少这些栏目。

### 1.1 研究方向（Research）

建议覆盖：

-   标准模型与 Higgs 物理；
-   超出标准模型（BSM）；
-   暗物质；
-   中微子物理；
-   味物理；
-   有效场论（EFT）；
-   电弱相变与引力波；
-   对撞机唯象学。

### 1.2 理论与计算（Theory & Computation）

建议覆盖：

-   量子场论基础；
-   散射振幅、截面和衰变宽度；
-   圈图与重整化；
-   FeynCalc、Mathematica 和 Python；
-   模型实现与 FeynRules/UFO；
-   数值积分、参数扫描与统计分析。

### 1.3 实验与唯象学（Phenomenology）

建议覆盖：

-   LHC 实验与公开结果；
-   理论预测与实验观测量；
-   实验约束重解释；
-   统计分析与全局拟合；
-   未来实验灵敏度及其假设。

### 1.4 代码与可复现研究（Code & Reproducibility）

建议覆盖：

-   计算脚本与代码仓库；
-   软件环境和依赖版本；
-   输入参数、数据和配置；
-   基准测试；
-   运行说明与预期输出；
-   结果验证、已知限制和版本记录。

### 1.5 文献与学习资源（Literature & Learning）

建议覆盖：

-   经典教材与专题综述；
-   论文阅读笔记；
-   研究生学习路线；
-   关键论文与后续引用；
-   学术研讨会、讲义和问题集。

### 1.5.1 学习与公开资源的边界

-   `/learning/:topic?` 属于登录后的学习与计算区；学习初稿、复现模板和未完成学术审核的材料不得因为前端路由或 `noindex` 而被视为安全，也不得自动进入官网。
-   每个学习专题应提供学习目标、前置知识、分节来源、公式的 LaTeX 源码、适用范围、自查题、版本和状态；“来源核对”“学术审核”“计算实测”须分开标记，不能互相替代。
-   公开资源只能由经过批准的白名单驱动，按文献与综述、实验与数据、计算与复现说明用途；外部资源只作链接，不嵌入第三方脚本、图片或追踪。
-   公开研究说明和资源链接应可静态访问；客户端筛选不得调用内部接口。详细的已实现范围、测试与证据边界分别记录在 `docs/audit/官网研究方向与资源导航.md` 和 `docs/audit/学习与计算补充验收.md`。

### 1.6 团队与学术活动（People & Activities）

如果网站是正式研究组网站，建议展示：

-   研究人员及经核实的职务信息；
-   研究方向与论文成果；
-   学术报告、研讨会和招生信息；
-   官方联系方式与单位链接。

如果网站是个人维护的学术资源库，应明确维护主体，避免让访问者误以为所有内容均代表学校或研究组的正式立场。

## 2. 首页应解决的五个问题

访问者打开首页后，应能迅速回答：

1.  这个网站研究什么？
2.  面向本科生、研究生还是专业研究人员？
3.  有哪些正在进行或已经完成的研究？
4.  能否找到对应论文、代码和实验资料？
5.  如何进一步学习、参与研究或联系维护者？

建议首页依次展示：

1.  一句话介绍和研究方向入口；
2.  4--6 个研究主题卡片；
3.  最近更新的论文、研究笔记或计算项目；
4.  重要代码库和实验数据入口；
5.  入门学习路线；
6.  团队介绍、维护者、更新时间和联系方式。

首页不宜只是研究方向的罗列，也不宜塞入过多论文标题。重点是让访问者清楚知道下一步应该去哪里。

## 3. 每个研究专题的统一模板

建议所有专题页遵循同一内容规范。

  模块             必须回答的问题
  ---------------- --------------------------------------------------
  研究动机         为什么研究这个问题？标准模型解释不了什么？
  理论框架         使用什么模型、拉格朗日量和基本假设？
  核心推导         质量谱、混合角、振幅、截面或有效势如何得到？
  计算方法         使用哪些解析方法、软件和数值算法？
  实验检验         哪些数据能够约束这个模型？
  结果状态         哪些结论已验证，哪些只是预测或待检验假设？
  可复现资料       代码、参数、输入数据、软件版本和运行方法在哪里？
  参考文献         哪些是原始论文、权威综述和最新实验结果？
  假设与适用范围   近似条件是什么？哪些参数区间不能使用这些公式？
  更新记录         作者、版本、最后核查日期和变更说明是什么？

建议设置固定的"**假设、近似与适用范围**"栏目。高能物理中的许多问题不是计算器算错，而是把近似结果用于不适用的参数区间。

## 4. 网站工程检查清单

### 4.1 搜索引擎与页面可见性

建议检查：

-   页面是否采用服务端渲染或静态预渲染；
-   每个路由是否有独立 HTML 标题和描述；
-   是否设置 canonical URL；
-   `robots.txt` 和 `sitemap.xml` 是否存在且配置正确；
-   站内页面能否被正常发现和索引；
-   数学公式是否有可访问的文本表示；
-   正文是否过度依赖客户端 JavaScript 才能读取。

这不意味着必须放弃 React
等前端框架，而是要确保科研内容不只存在于浏览器执行后的状态中。

### 4.2 可访问性与使用体验

重点检查：

-   手机端菜单、表格、公式和图片是否正常显示；
-   键盘能否完成主要导航；
-   正文和背景的对比度是否足够；
-   图片是否有有意义的替代文本；
-   公式是否可以复制或提供 LaTeX 源码；
-   长页面是否有目录、锚点和回到顶部功能；
-   中英文内容是否具有一致的结构。

### 4.3 版本与内容维护

每个研究页面建议展示：

-   作者或维护者；
-   最后更新时间；
-   内容版本；
-   推荐引用格式；
-   相关代码版本；
-   已知问题；
-   后续计划。

建议设置有明确含义的内容状态：

-   **已验证：** 关键结论通过规定的检查；
-   **初步结果：** 已有推导或计算，但验证不完整；
-   **待独立复现：** 结果尚未通过独立实现或外部复核；
-   **已过时：** 结果、软件或实验数据需要更新。

这些标签应对应具体的验收规则，不能只作为装饰。

### 4.4 时效性内容

实验状态、运行计划、最新上限、软件版本和实验数据均可能变化。应为这类内容标注核查日期，并链接到官方来源。

例如，LHC 运行状态与升级计划应以 CERN
的最新官方信息为准，不应长期保留"即将开始"或"正在运行"等过时描述。

## 6. 基础理论一：标准模型与量子场论

这是网站的理论基础。如果基础内容不完整，后续 BSM
页面容易变成只有结论和参数图、缺少可追踪推导的资料汇编。

### 6.1 标准模型拉格朗日量

建议新增"标准模型拉格朗日量与电弱对称性破缺"专题。

#### 第一部分：规范群与场内容

\[
G\_{`\rm SM}=SU(3)\_C`\times SU(2)\_L`\times U(1)\_Y.
\]

解释夸克、轻子、Higgs 双重态和规范场在各规范群下的表示，并解释电荷关系

\[ Q=T_3+Y \]

所采用的超荷归一化约定。

#### 第二部分：标准模型拉格朗日量

至少把内容拆成规范场、费米子动能项、Higgs 项和 Yukawa 相互作用：

\[
``
\begin{aligned}
\mathcal L_{\rm SM}={}&
-\frac14 G_{\mu\nu}^A G^{A\mu\nu}
-\frac14 W_{\mu\nu}^I W^{I\mu\nu}
-\frac14 B_{\mu\nu}B^{\mu\nu}\\
&+\sum_\psi \bar\psi i\!\not\!D\psi
+(D_\mu H)^\dagger(D^\mu H)\\
&-V(H)+\mathcal L_{\rm Yukawa}.
\end{aligned}
```
\]

每一项都要说明物理意义，并展示如何从中推导 Feynman 规则。

#### 第三部分：电弱对称性破缺

从

\[ H=`\frac{1}{\sqrt2}
``
\begin{pmatrix}
0\\v+h
\end{pmatrix}
```
\]

出发，推导 (W\^`\pm)、(Z) 和 Higgs 的质量，以及费米子质量与
Yukawa 耦合的关系。

#### 第四部分：味混合与中微子

分别解释 CKM 矩阵、PMNS
矩阵、质量本征态与相互作用本征态的区别，以及最小标准模型无法解释非零中微子质量的问题。

### 6.2 散射振幅、截面与衰变宽度

应从 S 矩阵和 Feynman 规则开始，最终连接到可以与实验比较的观测量。

\[ d`\sigma= `\frac{1}{\text{flux}},
`\overline{|\mathcal M|^2},d`\Phi\_n, \]

以及

\[ `\Gamma(A`\to f)= `\frac{1}{2m_A}
`\int d`\Phi\_f,`\overline{|\mathcal M|^2}. \]

需要明确说明：

-   初态平均和末态求和；
-   自旋、颜色因子；
-   两体和多体相空间；
-   相同末态的统计因子；
-   衰变宽度、分支比与总宽度；
-   树级、圈级以及高阶 QCD 修正；
-   质量无关极限、阈值行为和量纲检查。

至少提供三个可独立验证的完整例题，例如
(h`\to f`\bar f)、矢量玻色子衰变和一个简单的
(2`\to2) 散射过程。

**验收标准：**
读者能够从拉格朗日量推导振幅，再从振幅推导截面或衰变宽度，而不是直接抄用最终公式。

## 7. 基础理论二：BSM 模型构建与一致性检查

建议新增统一的"BSM 模型构建与一致性检查"专题。

### 7.1 每个新模型的最低检查要求

-   明确规范群、粒子场、规范表示和全部电荷；
-   写出完整拉格朗日量并检查规范不变性；
-   检查规范反常及所需的反常抵消条件；
-   推导标量势极小条件、质量谱和混合矩阵；
-   推导相关粒子的相互作用顶点；
-   计算主要衰变宽度、分支比和散射过程；
-   检查真空稳定性、微扰性、幺正性和 RG 演化；
-   整理电弱精确测量、味物理和低能约束；
-   整理对撞机、暗物质和宇宙学约束；
-   检查近似条件、EFT 适用范围和极限情况。

### 7.2 参数空间必须分类

**理论上可以构造的参数点，不等于实验允许的参数点。**

每个模型的参数扫描都应分别记录：

1.  理论上可实现的区域；
2.  在已检查实验约束下仍允许的区域；
3.  已被实验排除的区域；
4.  有效场论近似不再可靠的区域；
5.  尚未评估的区域。

还应说明采用的参数范围、先验、扫描方法和排除条件。不能仅凭一条微扰性上界就宣称得到了完整的实验允许窗口。

## 8. 专题一：Higgs 门户与标量混合

Higgs
门户适合展示网站的研究深度，因为它能将模型构建、解析推导、实验约束和数值扫描连接起来。

### 8.1 从势能开始

考虑标准模型 Higgs 双重态 (H) 与带额外 (U(1)') 电荷的复标量 (S)：

\[
``
\begin{aligned}
V(H,S)={}&-\mu_H^2 H^\dagger H
-\mu_S^2 S^\dagger S\\
&+\lambda_H(H^\dagger H)^2
+\lambda_S(S^\dagger S)^2\\
&+\lambda_{HS}(H^\dagger H)(S^\dagger S).
\end{aligned}
```
\]

在两者都获得真空期望值的情况下，取

\[ H\^0=`\frac{v+h}{\sqrt2}, `\qquad
S=`\frac{v_S+s}{\sqrt2}. \]

在这一势能与场归一化约定下，极小条件为

\[ `\mu\_H\^2=`\lambda\_H
v^2+`\frac{\lambda_{HS}}2v_S^2, \]

\[ `\mu\_S\^2=`\lambda\_S
v_S^2+`\frac{\lambda_{HS}}2v^2. \]

标量质量矩阵为

\[ `\mathcal M\^2=
``
\begin{pmatrix}
2\lambda_Hv^2 & \lambda_{HS}vv_S\\
\lambda_{HS}vv_S & 2\lambda_Sv_S^2
\end{pmatrix}
```
. \]

混合角满足

\[ `\tan 2`\theta= `\frac{2\lambda_{HS}vv_S}
{2`\lambda\_Hv\^2-2`\lambda\_Sv_S\^2}. \]

网页不能只给出结果，还应解释推导、符号约定、近简并质量附近的行为，以及不同混合矩阵定义导致的符号差异。

### 8.2 必须补充的研究内容

1.  标量质量本征值与本征态；
2.  混合角与物理耦合的关系；
3.  Higgs 信号强度和新标量衰变；
4.  势能有界条件、真空稳定性与微扰性；
5.  Higgs 隐形衰变及其他实验约束；
6.  标量质量、混合角、门户耦合之间的参数映射；
7.  近简并质量情形下不适用的近似；
8.  高阶修正与重整化方案的影响。

还应专门解释：**树级门户耦合取零，并不自动保证量子修正后仍然为零。**
是否会生成相应的混合或耦合项，要通过具体模型的对称性和圈图计算判断。

### 8.3 应提供的计算材料

-   势能和极小条件的符号计算脚本；
-   质量矩阵对角化与本征值检查；
-   混合角与质量参数的独立数值测试；
-   真空稳定性和微扰性检查；
-   与实验约束连接的参数扫描示例。

## 9. 专题二：(U(1)*{L*`\mu-L\_`\tau}) 与新规范相互作用

建议将其建设为完整模型专题，而不只是介绍额外规范玻色子及其现象学。

### 9.1 模型必须讲清楚的部分

-   (U(1)*{L*`\mu-L\_`\tau}) 的电荷赋值；
-   规范反常抵消；
-   新规范玻色子的质量来源；
-   规范动能混合；
-   中微子质量与味结构；
-   缪子反常磁矩；
-   暗物质与新标量的联系；
-   中微子三轻子反应、低能实验和对撞机约束。

若标量 (S) 的规范荷为 (q_S)，采用

\[ `\langle S`\rangle=`\frac{v_S}{\sqrt2}, \]

则由该标量破缺 (U(1)') 产生的规范玻色子质量为

\[ m\_{Z'}=\|q_S\|g_Xv_S. \]

只有在 (q_S=2) 的具体约定下，才有

\[ m\_{Z'}=2g_Xv_S. \]

网站应明确说明电荷归一化，不能把这个系数当成适用于所有模型的普遍公式。

### 9.2 缪子反常磁矩

建议从新矢量玻色子的单圈贡献开始推导：

\[ `\Delta a\_`\mu= `\frac{g_X^2}{8\pi^2}
`\int*0\^1 dx, `\frac{2x(1-x)^2m_\mu^2}
{(1-x)^2m\_`\mu^2+xm*{Z'}\^2}, \]

这里采用纯矢量耦合的常见约定。

需要进一步讨论：

-   (m\_{Z'}`\ll m\_`\mu) 和
    (m\_{Z'}`\gg m\_`\mu) 的极限；
-   理论预测的不确定性；
-   与实验测量的比较方法；
-   其他实验约束是否排除相同参数区域；
-   仅解释 (`\Delta a\_`\mu) 是否足以使整个模型成立。

解释某一个观测量，不代表模型已经通过全部实验检验。

## 10. 专题三：有效场论与 UV--EFT 一致性

如果网站面向高能理论物理研究人员，这一部分应作为核心专题。

### 10.1 基本内容

从

\[ `\mathcal L\_{`\rm EFT} =
`\mathcal L\_{`\rm SM}
+`\sum\_{d\>4}`\sum\_i
`\frac{C_i^{(d)}}{\Lambda^{d-4}} `\mathcal O_i\^{(d)} \]

开始，解释：

-   算符维数与有效理论的能标展开；
-   Weinberg 五维算符与中微子质量；
-   六维 SMEFT 算符及其 Wilson 系数；
-   算符基底和归一化约定；
-   从 UV 模型到 EFT 的树级和圈级匹配；
-   Wilson 系数的重整化群演化；
-   低能 EFT 与 SMEFT 之间的匹配；
-   EFT 截断误差与高能区有效性。

### 10.2 必须专门解释的陷阱

**EFT 不是在任意能量下都有效。**
如果研究过程的特征能量接近或超过新物理能标
(`\Lambda)，就必须重新评估 EFT 截断是否可靠。

**不能任意混合不同阶的修正。**
截断到特定阶时，线性维六算符贡献、维六算符平方项和维八算符贡献之间的相对重要性，需要结合采用的计数规则说明。

**匹配与 RG 演化必须使用一致约定。** 算符基底、Wilson
系数归一化、重整化方案和尺度都应记录。

### 10.3 建议的实战例题

-   由简单重粒子交换导出四费米算符；
-   从 UV 标量模型导出 Higgs 门户相关低能相互作用；
-   对比 UV 完整模型与 EFT 的截面；
-   展示 EFT 在高能区失效或偏离 UV 预测的例子；
-   给出算符系数扫描和实验拟合代码。

参考阅读可从 SMEFT 综述开始，例如 Brivio 与 Trott 的综述 *The Standard
Model as an Effective Field
Theory*：<https://arxiv.org/abs/1706.08945>。

## 11. 专题四：暗物质理论与实验检验

暗物质专题至少应包含宇宙学、直接探测、间接探测和对撞机搜索四部分，并说明它们之间的互补关系。

### 11.1 热遗迹与宇宙学

热冻结模型的基础方程为

\[ `\frac{dn_\chi}{dt}+3Hn\_`\chi =
-`\langle`\sigma v`\rangle
`\left(n\_`\chi^2-n\_{`\chi,`\mathrm{eq}}^2`\right).
\]

需要解释：

-   热平衡与冻结过程；
-   暗物质湮灭截面与遗迹丰度；
-   共振、共湮灭和阈值效应；
-   非热产生机制的区别；
-   过度产生与产生不足的判据。

### 11.2 直接探测

对于弹性、自旋无关的 WIMP--原子核散射，一个常用表达式为

\[ `\frac{d\sigma_A}{dE_R} = `\frac{m_A\sigma_A^0}
{2`\mu\_A^2v^2} F_A\^2(q), `\qquad
q=`\sqrt{2m_AE_R}. \]

这里 (m_A) 是核质量，(`\mu\_A) 是 WIMP--原子核约化质量，(E_R)
是核反冲能量，(F_A(q)) 是核形状因子。

网站应解释公式中的每个量，并说明核形状因子、核子耦合以及实验效率如何影响最终事件率。

### 11.3 核结构与有效算符

若要把直接探测部分做到研究级，建议继续加入：

-   自旋无关与自旋相关相互作用；
-   非弹性散射；
-   核响应函数与非相对论有效理论；
-   单核子与双核子流的区别；
-   核结构不确定性；
-   Helm 形状因子的适用范围；
-   XENON、LZ、PandaX 等实验的结果与分析假设。

需要区分粒子物理算符、核子级耦合和原子核响应。这三者不是同一个层次的描述。

### 11.4 约束汇总表

  约束类别     需要记录的内容
  ------------ ---------------------------------------
  遗迹丰度     采用的宇宙学历史、产生机制和参数假设
  直接探测     核响应、实验效率、曝光量和统计方法
  间接探测     末态、湮灭截面、天体物理假设
  对撞机       搜索道、实验能量、积分亮度和模型实现
  理论一致性   稳定性、微扰性、幺正性和 EFT 适用范围

不要把不同实验在不同假设下得到的排除曲线直接叠加后，称为对整个模型的完整约束。

## 12. 专题五：电弱相变与引力波

如果网站包含粒子物理与宇宙学交叉研究，这个专题值得独立建设。

### 12.1 有限温有效势

至少介绍

\[ V\_{`\rm eff}(`\phi,T) =
V_0(`\phi)+V\_{`\rm CW}(`\phi)
+V_T(`\phi,T)+V\_{`\rm daisy}(`\phi,T), \]

并分别说明：

-   树级势；
-   Coleman--Weinberg 圈级修正；
-   有限温修正；
-   Daisy 重求和；
-   临界温度与成核温度；
-   一阶相变与连续相变的区别。

必须强调：有限温有效势的计算存在规范依赖、微扰展开和重求和等问题。一个看起来存在势垒的有效势，不应自动被视为完整、可靠的强一阶相变证据。

### 12.2 相变参数

建议解释

\[ `\frac{\beta}{H_*} `\simeq T\_*`\left.
`\frac{d(S_3/T)}{dT}`\right\|*{T**}, \]

其中 (S_3) 是三维热成核作用量。还应介绍
(`\alpha)、(`\beta/H\_\*)、泡壁速度、成核与渗流、相变是否完成等概念，并说明定义和计算约定。

### 12.3 引力波预测

需要说明不同引力波来源的区别，包括：

-   声波；
-   流体湍流；
-   泡壁碰撞及相关场动力学过程。

进一步讨论谱峰频率、谱幅、相变能量转化效率以及探测器灵敏度。

每张预测图都应标明输入参数、理论假设、使用的谱模型和不确定性。不能仅凭引力波信号达到某个灵敏度范围，就断言未来实验必然能够探测到。

## 14. 专题七：对撞机唯象学与实验重解释

这一部分应把理论模型与真实实验连接起来，而不是停留在理论截面公式。

### 14.1 标准工作流

1.  **理论模型：** 拉格朗日量、粒子谱、相互作用；
2.  **模型实现与矩阵元：** FeynRules、UFO、MadGraph 等；
3.  **事例生成与探测器模拟：** Pythia、Delphes 等适用工具；
4.  **分析、统计与实验比较：** 选择效率、背景、似然和排除区间；
5.  **验证与可复现结果：** 基准过程、参数文件、版本和不确定性。

### 14.2 具体内容

-   部分子截面与质子碰撞截面的区别；
-   PDF 卷积和因子化尺度；
-   QCD 高阶修正、K 因子及理论不确定性；
-   信号产生、背景建模和选择效率；
-   探测器模拟与真实实验分析之间的差异；
-   公开结果的重解释方法及适用限制。

强子碰撞总截面的基本结构为

\[ `\sigma(pp`\to X) =
`\sum\_{ij}`\int dx_1dx_2,
f_i(x_1,`\mu\_F)f_j(x_2,`\mu*F)
`\hat`\sigma*{ij`\to X}. \]

网站应从该公式出发解释
PDF、部分子截面和尺度依赖，而不是只给出一个数值截面。

对于最新 Higgs 产生截面和理论不确定性，应优先引用 LHC Higgs Cross
Section Working Group 的对应版本，而不是长期沿用旧版数值：

-   <https://twiki.cern.ch/twiki/bin/view/LHCPhysics/LHCHXSWG>

## 15. 专题八：统计分析

实验约束最终来自统计分析，因此建议专门设置统计方法专题。

应包括：

-   似然函数与 profile likelihood；
-   贝叶斯与频率学派方法的区别；
-   置信区间与上限；
-   (CL_s) 方法；
-   信号显著性及其适用条件；
-   多重检验与 look-elsewhere effect；
-   系统误差与相关矩阵；
-   多实验联合拟合；
-   先验、扫描范围和参数退化。

例如，常见的

\[ Z`\simeq `\frac{S}{\sqrt B} \]

只是在一定近似条件下使用的简化显著性估计，不能代替真实分析中的完整统计推断。

网站还应解释：理论允许区、实验排除区和统计上限不是同一个概念。

## 16. 专题九：FeynCalc 与可复现计算

FeynCalc 是用于 Mathematica 的量子场论符号计算工具，支持 Dirac
代数、迹、颜色代数、张量约化及圈图计算相关操作。建议以官方文档和示例为主要参考：

-   官方主页：<https://feyncalc.github.io/>
-   官方文档：<https://feyncalc.github.io/FeynCalcBook/>

### 16.1 建议新增的 FeynCalc 页面

  页面         应包含的内容
  ------------ ---------------------------------------------
  安装与环境   Mathematica 版本、FeynCalc 版本、安装与加载
  约定与符号   度规、四维与 (D) 维、指标、Dirac 矩阵
  树级振幅     从顶点到振幅，再到自旋求和
  Dirac 迹     迹恒等式、(`\gamma\_5) 与维数约定
  圈图计算     积分约化、发散结构、重整化和主积分
  独立验证     极限、量纲、解析公式和另一种计算方法
  常见错误     指标混淆、符号约定、展开顺序和不适当的简化

### 16.2 不要只发布代码，要发布验证证据

每个计算示例至少包含：

1.  输入的拉格朗日量或振幅；
2.  使用的约定与假设；
3.  完整计算脚本；
4.  关键中间结果；
5.  最终结果；
6.  独立验证方法；
7.  失败情况及已知限制。

例如，计算一个圈图后，不能只展示 Mathematica
输出。还应检查量纲、紫外发散结构、已知质量极限，并在适当情况下与独立解析结果比较。

### 16.3 复现规范

每个代码项目至少记录：

-   Git commit 或版本标签；
-   输入参数与数据版本；
-   Mathematica、FeynCalc、Python 等软件版本；
-   运行环境及依赖；
-   随机数种子（如适用）；
-   预期输出与容差；
-   运行时间及硬件要求；
-   已知数值稳定性问题。

CERN 的 REANA
项目可作为可复现工作流的参考。网站可以借鉴其组织代码、数据、运行环境和工作流的思路，不一定需要直接部署
REANA：

-   <https://reanahub.io/>

### 20.2 计算可验证

关键结果具有独立的解析或数值检查。

### 20.3 实验可追溯

每项约束都有数据、论文和版本依据。

### 20.4 结论不混淆

理论可实现、实验允许、实验排除和未评估区域分开。

### 20.5 近似透明

明确圈级、重整化方案、参数范围与 EFT 适用条件。

### 20.6 代码可复现

读者能够知道运行什么代码、使用什么输入，以及怎样判断输出正确。

### 20.7 内容可维护

论文、实验结果、软件和参数更新后，网站可以准确地同步更新。

## 24. 统一实施顺序

### 阶段 A：权限与部署可靠性（P0/P1）

1. 修复 SEC-01 至 SEC-04 的权限、Token 与限速问题；复核 SEC-05、SEC-06。
2. 明确管理员、教师、资料创建者、普通成员的权限矩阵并在服务端执行。

### 阶段 B：性能与可访问性（P1）

1. 修复 WEB-001、WEB-002，分别拆分公开入口和工作台代码。
2. 完成 WEB-006 的实际设备与键盘验收。
3. 记录优化前后请求、JS 体积、LCP/INP；目标数值须结合真实测试确认，不以构建警告本身作为最终指标。

### 阶段 C：论文与物理专题（P1/P2）

1. 人工确认代表论文，补齐 DOI、期刊、作者、出版状态、分类和来源。
2. 增加中微子、相变/引力波、量子计量学等有文献支持的主题。

**验收：** arXiv/DOI 链接有效，元数据与原始记录一致，预印本不误标为已发表；重要公式可追溯到定义与假设；关键结果有独立检查。

### 阶段 D：SEO 与长期维护（P2/P3）

1. 完成 WEB-005 的公开页面元数据与索引配置。
2. 建立每 3–6 个月人工核查论文的维护周期；重要成果发表后及时更新。

## 25. 问题关闭规则与审计结论

- P0：涉及数据泄露、公开误导或关键服务无法安全运行的阻断问题。
- P1：权限边界、部署可靠性、严重性能或核心学术内容问题。
- P2：SEO、内容结构、可用性和一般体验问题。
- P3：非必要增强功能与装饰性改进。

问题只有在代码修改后通过对应测试或人工复核，并记录证据与日期，才可标记为关闭。源码审查、部署成功、页面渲染和学术内容审核是不同的验收阶段，不可互相替代。

本轮尚未完成的工作包括：线上逐屏检查、完整测试套件、Lighthouse、真实角色权限矩阵、生产数据库与密钥检查、渗透测试，以及代表论文的课题组最终确认。完成前不得宣称这些项目已通过验收。

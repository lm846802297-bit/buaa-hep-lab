# 《命运石之门》视觉语言转译：课题组网站设计与验收

## 1. 目标与边界

目标是在北航粒子物理研究组网站中加入一套可选的“世界线终端（Worldline Console）”皮肤，并把《命运石之门》的视觉语言转译成适合科研网站的交互。它是可选皮肤，不替换 Quiet Research 默认风格，也不修改既有账号、科研资料、权限、API 或数据库逻辑。

实现只借鉴抽象的视觉语汇：暖白工程图纸、深蓝线稿、精密仪器刻度与数学公式作为科研主体；以复古终端标签、时间戳、细扫描线、短暂信号故障和世界线刻度偏移作为第二层交互反馈。不复制原作角色、标志、原画、截图、音乐或其他受版权保护的素材。

## 2. 研究依据

- [《STEINS;GATE》官方日文网站](https://steinsgate.jp/)将作品描述为以真实科学现象为骨架的科幻悬疑，并列出角色设计、道具设计和美术指导等制作分工。这支持从“科学设定 + 设备美术 + 信息呈现”提炼设计，而非仅模仿动漫角色。
- [《STEINS;GATE 0》官方游戏介绍](https://steinsgate0.jp/game/)明确描述手机应用的使用方式会影响故事发展，并介绍 Amadeus 与 RINE 消息交互。这为“操作应引起清楚的状态反馈”提供了交互层面的参考。
- [官方英文视觉小说网站](https://steins-gate.com/)也将分支剧情与手机操作列为核心特色。
- 视觉参考关键词：世界线变动仪/时间戳、复古设备外壳、终端信息行、局部 CRT 扫描、短时信号故障与世界线刻度偏移。暖白科学蓝图是本站获批的主要视觉基底；以上为抽象设计转译，不表示原作所有界面都采用同一配色或同一实现。

## 3. 视觉令牌与色彩美术规范

### 3.1 美术方向

**当前视觉基准是已获认可的暖白科学蓝图概念图。** 官网及纸张背景模式以暖白/浅灰纸张、细密工程网格、手绘齿轮与圆规、轨道草图、数学公式和仪器刻度为主体；搭配优雅的衬线主标题、墨色正文、深海军蓝线稿，以及极少量琥珀色信号。右侧实验装置或碰撞示意承担主视觉，排版采用学术编辑式留白与清晰的信息层级。

《命运石之门》不是替换上述基底的整站黑色皮肤，而是第二层设计语言：复古终端标签、时间戳、手机/邮件信息感、CRT 细扫描、短暂信号故障与世界线刻度偏移。它们应该像精密科研档案中的设备状态，而不是通用科幻驾驶舱。不得复制原作角色、Logo、截图或具体 UI 素材；颜色是本站原创设计令牌，不宣称为原作官方色板。协作空间若选择非纸张动态背景，仍保留与该背景相配的深色终端配色。

### 3.3 配色与画面层级

- **纸张与线稿是主体，光效是注释。** 全站底色维持暖白，细密网格和齿轮/圆规/轨迹以低透明度呈现；网格不能形成强烈摩尔纹，也不能与正文抢对比。
- **真实科学内容优先。** 碰撞图、探测器图、公式与研究专题需要清晰可读；示意 SVG 必须标明是示意，不得伪装成真实实验事件或观测数据。
- **深蓝负责结构。** 标题、导航、按钮和关键线稿使用海军蓝；青灰只用于轨迹和状态线，不铺满卡片。
- **琥珀色只标记异常。** 它用于少量状态灯、局部碰撞闪光与世界线偏移，不替代正文色或大面积背景。
- **复古终端是局部层。** FIELD MONITOR、时间戳、读数框和扫描线可以出现，但必须依附在纸面/浅色设备表面，避免整站变成深色 HUD。
- **动效必须短、可解释、可关闭。** 世界线变动的扫描、刻度偏移、信号故障和粒子爆发统一在约 1.8 秒内完成；稳定状态不持续闪烁。尊重 `prefers-reduced-motion`。
- **不做通用霓虹赛博朋克。** 不使用全屏随机霓虹、紫青渐变铺满卡片、无意义数字雨、厚重外发光或持续摇晃。

### 3.4 可读性基线

正文与公式使用深墨色，辅助文字使用经过对比度检查的蓝灰色；关键正文、按钮文字和小型标签必须在实际复合背景上检查对比度。网格、齿轮和轨迹均为装饰层，不能穿透正文形成干扰。卡片/弹窗默认使用实体浅色表面，阴影轻量；交互状态不能只靠颜色区分，必须保留文字、图标、形状或位置变化。
### 3.5 外观调谐图标的颜色契约

图标使用通用 `--theme-tuner-*` 变量，所有普通皮肤都从 `--text`、`--surface`、`--line` 和 `--accent` 派生颜色；因此切换皮肤后不需要为每个皮肤维护一份独立 SVG。

世界线蓝图只覆盖组件级变量：
- 外环：墨色与蓝灰混合，形成细腻的仪器刻度；
- 四向刻度：低饱和青灰；中心星点：青灰；双节点：琥珀/陶土色；
- 按钮边界：海军蓝与浅灰混合；
- 悬停状态：轻微边界提亮和短促信号反馈，不使用持续霓虹光晕。

图标不得在组件内写死颜色值。所有颜色变化必须来自当前主题变量，世界线终端的专项增强则由 `[data-color-scheme="worldline-console"]` 下的变量覆盖实现。

中文正文保持网站原有可读字体；只有 eyebrow、徽标、数字和终端式元信息使用等宽字体。

## 4. 交互规范

### 官网风格入口
- 首页将外观调谐图标放在主导航栏右侧；研究专题、团队和学术活动等公开子页面在右上方保留同一入口。
- 图标由环形轨道、四向刻度、双调节点与中心星点组成；颜色完全来自主题变量，世界线终端使用青色核心 + 电蓝轨道的专项配色。
- 点击图标打开轻量选择面板，显示当前风格并提供全部公开皮肤选项；点击外部区域或按 Escape 可关闭。
- 选择器不再长期占据右下角，避免遮挡页面内容；图标具有可访问名称、键盘焦点样式和移动端适配。
- 公开官网皮肤继续使用独立的 `labhub_public_color_scheme`，不影响协作空间的个人主题。

### 悬停
- 可交互卡片在桌面指针设备上出现深蓝/青灰边界与轻微高光。
- 研究方向、论文、物理资源卡片可以配合细线高光、局部扫描和短促位移；避免无意义的持续抖动或大面积发光。
- 粒子碰撞径迹在悬停时流动；全局环境粒子与世界线变动粒子爆发已纳入当前实现。
- 触屏设备不依赖 hover 才能访问信息。

### 点击
- 按钮与链接在按下时可以出现亮度脉冲、信号扩散或短促的扫描反馈，但必须保留原有点击行为。
- 所有反馈使用 CSS，不拦截点击、不更改链接目标、不延迟业务操作。

### 世界线变动
- 选择/退出世界线蓝图皮肤时，只播放约 1.8 秒的刻度扩散、细扫描线、轻微色偏、故障切片与粒子爆发，不显示“世界线变动”文字或 HUD 面板；路由切换仍可显示读数面板。
- 在启用该皮肤时，公开页面或工作区路由切换会触发同类短动画。
- 动画层固定定位、`pointer-events: none`，不拦截用户操作。
- 动画可以在短时间内增强：纸白闪变、海军蓝刻度盘、横向信号偏移、向外爆发的粒子轨迹与浅色读数面板。效果必须在短时间内结束，不伪造实际世界线偏差率、实验读数或科研指标。

### 可访问性与性能
- 遵循 `prefers-reduced-motion: reduce`：禁用世界线切换动画和持续动效。
- 公开站点皮肤使用独立的 `labhub_public_color_scheme`；工作区偏好使用原有 `laborbit_color_scheme`。公开皮肤不得覆盖用户的工作区主题。
- 优先使用 CSS 与 Canvas 2D 实现粒子层，不引入 WebGL、视频、外部图片或音频依赖；控制粒子数量、监听页面可见性，并为减少动态效果偏好提供关闭路径。

## 5. 代码落点
- `frontend/src/composables/useThemeStyle.js`：注册 `worldline-console`，复用既有皮肤选择和持久化逻辑。
- `frontend/src/index.css`：调色板、终端细节、悬停/点击反馈与世界线过渡动画。
- `frontend/src/components/WorldlineEffects.vue`：监听皮肤与路由变化，驱动 Canvas 2D 环境粒子/爆发粒子；皮肤切换采用纯视觉转场，路由切换可显示世界线读数 HUD；同时处理减少动态效果、页面隐藏、尺寸变化和组件卸载。
- `frontend/src/components/PublicThemeSwitcher.vue`：以主题变量驱动的外观调谐图标和弹出式面板提供公开站点皮肤入口；首页嵌入导航栏，其他公开页面固定在右上角。
- `frontend/src/index.css`：定义通用 `--theme-tuner-*` 令牌、世界线终端的冷蓝黑/青色/电蓝/品红变量，以及 CRT 扫描线和信号层。
- `frontend/index.html`：首次绘制时识别新皮肤，避免刷新后先回退到其他配色再跳变。
- `frontend/src/composables/useThemeStyle.test.js`、`frontend/src/views/AntiFlickerAndNoticeTheme.test.js`、`frontend/tests/audit-browser-smoke.mjs`：状态、首屏和浏览器行为测试。

## 6. 分阶段实施

1. **阶段 A：高保真视觉基线**：当前基线改为暖白工程纸、海军蓝线稿、细密网格和优雅衬线标题；保留固定 SVG 技术底图中的齿轮、制图圆规、轨道弧线、仪器读数框和注释标签，降低透明度并改用纸面友好的混合模式。
2. **阶段 B：世界线动效**：已实现短时全屏视觉转场、RGB 色散、故障切片、扫描波、中心刻度盘和粒子爆发；主题切换不显示文字 HUD，路由切换可显示 HUD，效果结束后页面恢复稳定。
3. **阶段 C：粒子与环境反馈**：已加入低频漂浮粒子、粒子连接线、鼠标附近微粒偏移/连线、点击脉冲和世界线切换时的径向粒子爆发；后续可继续丰富粒子碰撞轨迹与局部能量脉冲。
4. **阶段 D：视觉验收**：桌面/平板/手机截图对照；测试性能、减少动态效果、键盘操作、不同皮肤切换和所有原有业务交互。

## 8. 精修路线

1. **阶段 A：高保真视觉基线**：首轮截图已完成桌面与手机视口核对。当前以暖白图纸和海军蓝线稿为主，硬件灰用于齿轮与仪器边缘，琥珀色只用于少量状态灯和世界线异常。
2. **阶段 B：世界线动效增强**：用单独的闪屏层控制全屏闪变，避免父级透明度把 HUD 一起淡化；在动效可读峰值截屏，检查中心刻度盘、故障切片、扫描波与 HUD 的层级。
3. **阶段 C/D：粒子特效与视觉回归**：继续核对环境粒子、鼠标附近微粒响应、点击脉冲与径向轨迹；在桌面、平板和 320/360/390px 手机视口检查排版、性能、可访问性、减少动态效果和原有交互。自动化测试通过不等于美术验收完成。

## 12. 本轮统一时间轴与验收要求（2026-10-21）

本轮不再把世界线演出理解为同时启动的若干独立效果，而是统一为一个约 1.8 s 的事件；底色保持纸白，故障只改变局部刻度与信号层：

1. **0–130 ms：点火** — 纸白/海军蓝短闪与中心刻度盘启动，页面结构和正文不移动。
2. **130–350 ms：传播** — 外环先扩散，内环延迟跟进；背景仪器刻度与齿轮短暂提亮。
3. **150 ms 起：粒子爆发** — Canvas 2D 粒子从中心释放，带轻微旋转曲率、平滑二次曲线拖尾和受限的局部碰撞闪光；不使用 WebGL。
4. **180–950 ms：信号故障** — 故障切片按先后顺序出现，而不是同一时刻闪烁；鼠标点击使用海军蓝与琥珀双脉冲。
5. **150–1700 ms（约 400 ms 达到可读亮度）：状态读数** — HUD 在扩散波之后进入，保持足够对比度，进度条随后完成；最后阶段逐步衰减。
6. **1800 ms：清理** — 清除转场状态与定时器；如果切到其他皮肤、启用减少动态效果或页面进入后台，则取消未完成的阶段和粒子任务。

## 13. HUD 读数阶段的确定性修复（2026-10-22）

上一轮 Chromium 日志在 HUD 读数检查中观察到 `opacity: 0`。本轮不放宽验收阈值，而是移除 HUD 可读性对 CSS 墙钟动画进度的隐式依赖。

- DOM 的 `data-phase="readout"` 生效时，HUD 停止独立淡入动画并保持 `opacity: 1`；
- 进入 `data-phase="decay"` 后，才运行独立的 580 ms 衰减动画；
- Chromium 烟测先等待 Vue 将 `readout` 写入 DOM，再检查计算样式；随后验证 `decay` 阶段已启用 `worldline-hud-decay`。

该修改仍需由最新 HEAD 的完整 CI 与截图 Artifact 验证；代码实现本身不构成视觉验收通过。

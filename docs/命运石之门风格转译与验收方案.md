# 《命运石之门》视觉语言转译：课题组网站设计与验收

## 1. 目标与边界

目标是在北航粒子物理研究组网站中加入一套可选的“世界线终端（Worldline Console）”皮肤，并把《命运石之门》的视觉语言转译成适合科研网站的交互。它是可选皮肤，不替换 Quiet Research 默认风格，也不修改既有账号、科研资料、权限、API 或数据库逻辑。

实现只借鉴抽象的视觉语汇：复古实验终端、琥珀色读数、暗色设备外壳、轻微扫描线、状态切换和手机/通知式反馈。不复制原作角色、标志、原画、截图、音乐或其他受版权保护的素材。

## 2. 研究依据

- [《STEINS;GATE》官方日文网站](https://steinsgate.jp/)将作品描述为以真实科学现象为骨架的科幻悬疑，并列出角色设计、道具设计和美术指导等制作分工。这支持从“科学设定 + 设备美术 + 信息呈现”提炼设计，而非仅模仿动漫角色。
- [《STEINS;GATE 0》官方游戏介绍](https://steinsgate0.jp/game/)明确描述手机应用的使用方式会影响故事发展，并介绍 Amadeus 与 RINE 消息交互。这为“操作应引起清楚的状态反馈”提供了交互层面的参考。
- [官方英文视觉小说网站](https://steins-gate.com/)也将分支剧情与手机操作列为核心特色。
- 视觉参考关键词：世界线变动仪/辉光数字、CRT 与点阵信息、低饱和暗底、琥珀橙高光、设备式边框、短暂的信号干扰。以上为设计分析与抽象提炼，不表示原作所有界面都采用同一配色或同一实现。

## 3. 视觉令牌与色彩美术规范

### 3.1 美术方向

采用“**旧式实验室设备 + 暖黑旧设备底色 + 洗旧卡其/灰橄榄阴影 + 琥珀辉光读数**”作为世界线终端的色彩骨架。参考《命运石之门》中的旧式显示设备、辉光数字、略显陈旧的实验室环境和低保真信号质感；将其转译为原创的科研网站视觉系统，而不是把全站做成纯橙色或高饱和霓虹界面。

官方《STEINS;GATE》网站可用于核对作品的科学悬疑定位与美术制作背景；色彩描述属于视觉分析，不是官方发布的标准色值。因此下表中的 HEX 是本项目自行定义、可测试的设计令牌，**不声称是原作的官方调色板**：
- 官方作品信息：[STEINS;GATE 官方网站](https://steinsgate.jp/)
- 视觉参考分析：[Steins;Gate CRT 视觉风格分析](https://designbycurio.com/zh/steins-gate-2011-crt)

### 3.2 核心配色

| 令牌 | 值 | 角色与使用规则 |
|---|---|---|
| 实验室暗底 `--bg` | `#15120f` | 带暖棕倾向的暗黑，不用绝对纯黑 |
| 主面板 `--panel-solid` | `#1C211B` | 设备外壳、卡片和弹出面板 |
| 玻璃表面 `--surface` | `rgba(31, 25, 19, .88)` | 半透明暖黑棕；不让模糊效果代替边界 |
| 主文字 `--text` | `#F0E9D9` | 温暖的浅灰米色，保证长文和公式可读 |
| 次级文字 `--soft` | `#D1C8B5` | 说明文字、次级标题 |
| 辅助文字 `--muted` | `#A5A28E` | 时间、来源、次要元信息 |
| 主信号 `--accent` / `--worldline-amber` | `#E6A64B` | 琥珀色读数、当前状态、主按钮和关键节点 |
| 高亮信号 `--worldline-amber-hot` | `#FFD08A` | 焦点、短暂信号峰值；避免大面积铺色 |
| 洗旧卡其/灰橄榄辅助色 `--worldline-khaki` | `#8FAA9C` | 环形轨道、次级刻度和旧设备环境反光 |
| 锈红警示 `--worldline-rust` | `#D5795E` | 错误或危险状态专用，不作为常规强调色 |
| 柔和成功 `--success` | `#A9B88E` | 低饱和的状态确认 |
| 细边界 `--line` | `rgba(198, 157, 104, .22)` | 温暖灰金色细边框；不使用高亮粗边 |
| 圆角 `--radius` | 14 px | 保留设备面板感，但避免所有元素都变成胶囊形 |

### 3.3 配色比例与层级

- **暗中性色是主体**：背景、面板和长文本区域保持低饱和暗色；琥珀色只用于需要被注意到的信息，不把每个标题、边框和图标都染橙。
- **琥珀负责“信号”**：主操作、选中状态、关键状态点和调谐图标的核心节点使用琥珀色。
- **洗旧卡其/灰橄榄负责“设备环境”**：环形轨道、刻度、背景微光和少量次级状态使用洗旧卡其/灰橄榄色，提供冷暖对比。它是辅助色，不取代琥珀色成为主强调色。
- **锈红只表达风险**：错误和危险状态才使用锈红；不要把它用于普通链接或装饰。
- **CRT 质感只做轻微表层**：扫描线和环境光保持很低的不透明度；不让扫描线降低正文、公式、按钮标签的对比度。
- **避免的方向**：纯黑 + 亮橙满屏、赛博朋克式高饱和青紫、持续闪烁、厚重霓虹外发光、全站等宽字体、用发光效果代替信息层级。

### 3.4 可读性基线

按 WCAG 相对亮度公式计算，下列颜色与基底 `#15120f` 的对比度约为：
- 主文字 `#F0E9D9`：15.2:1
- 次级文字 `#D1C8B5`：11.1:1
- 辅助文字 `#A5A28E`：7.2:1
- 琥珀主信号 `#E6A64B`：8.7:1
- 洗旧卡其/灰橄榄 `#8FAA9C`：7.4:1

这些值针对纯基底色计算；实际页面仍需检查半透明面板、渐变、悬停状态与文字背景组合。长段中文、公式和论文摘要优先使用主/次级文字，不依赖低对比度的颜色表达含义。错误、成功和选中状态也必须保留文字或形状提示，不能只靠颜色区分。

### 3.5 外观调谐图标的颜色契约

图标使用通用 `--theme-tuner-*` 变量，所有普通皮肤都从 `--text`、`--surface`、`--line` 和 `--accent` 派生颜色；因此切换皮肤后不需要为每个皮肤维护一份独立 SVG。

世界线终端只覆盖组件级变量：
- 外环：主文字与洗旧卡其/灰橄榄混合，呈现冷色仪器刻度；
- 四向刻度：低亮度灰橄榄；
- 中心星点和双节点：琥珀色；
- 按钮边界：灰橄榄与暖灰金混合；
- 悬停状态：琥珀环光叠加极弱的灰橄榄环境光。

图标不得在组件内写死颜色值。所有颜色变化必须来自当前主题变量，世界线终端的专项增强则由 `[data-color-scheme="worldline-console"]` 下的变量覆盖实现。

中文正文保持网站原有可读字体；只有 eyebrow、徽标、数字和终端式元信息使用等宽字体。

## 4. 交互规范

### 官网风格入口
- 首页将外观调谐图标放在主导航栏右侧；研究专题、团队和学术活动等公开子页面在右上方保留同一入口。
- 图标由环形轨道、四向刻度、双调节点与中心星点组成；颜色完全来自主题变量，世界线终端使用琥珀核心 + 卡其/灰橄榄轨道的专项配色。
- 点击图标打开轻量选择面板，显示当前风格并提供全部公开皮肤选项；点击外部区域或按 Escape 可关闭。
- 选择器不再长期占据右下角，避免遮挡页面内容；图标具有可访问名称、键盘焦点样式和移动端适配。
- 公开官网皮肤继续使用独立的 `labhub_public_color_scheme`，不影响协作空间的个人主题。

### 悬停
- 可交互卡片在桌面指针设备上出现琥珀色边框与轻微辉光。
- 研究方向、论文、物理资源卡片最多上移 2 px；不使用持续抖动或大幅缩放。
- 粒子碰撞径迹只在悬停示意图时短暂流动。
- 触屏设备不依赖 hover 才能访问信息。

### 点击
- 按钮与链接在按下时出现轻微亮度/位移反馈。
- 所有反馈使用 CSS，不拦截点击、不更改链接目标、不延迟业务操作。

### 世界线变动
- 选择/退出世界线终端皮肤时，出现约 0.9 秒的扫描线、信号带和“世界线变动”提示。
- 在启用该皮肤时，公开页面或工作区路由切换会触发同类短动画。
- 动画层固定定位、`pointer-events: none`，不拦截用户操作。
- 动画只显示“观测状态已更新”等非数据性文字；不伪造实际世界线偏差率、实验读数或科研指标。

### 可访问性与性能
- 遵循 `prefers-reduced-motion: reduce`：禁用世界线切换动画和持续动效。
- 公开站点皮肤使用独立的 `labhub_public_color_scheme`；工作区偏好使用原有 `laborbit_color_scheme`。公开皮肤不得覆盖用户的工作区主题。
- 不增加 WebGL、视频、外部图片或音频依赖。

## 5. 代码落点
- `frontend/src/composables/useThemeStyle.js`：注册 `worldline-console`，复用既有皮肤选择和持久化逻辑。
- `frontend/src/index.css`：调色板、终端细节、悬停/点击反馈与世界线过渡动画。
- `frontend/src/components/WorldlineEffects.vue`：监听皮肤与路由变化，显示短暂过渡层。
- `frontend/src/components/PublicThemeSwitcher.vue`：以主题变量驱动的外观调谐图标和弹出式面板提供公开站点皮肤入口；首页嵌入导航栏，其他公开页面固定在右上角。
- `frontend/src/index.css`：定义通用 `--theme-tuner-*` 令牌、世界线终端的暖琥珀/灰橄榄专属变量和低强度 CRT 表层。
- `frontend/index.html`：首次绘制时识别新皮肤，避免刷新后先回退到其他配色再跳变。
- `frontend/src/composables/useThemeStyle.test.js`、`frontend/src/views/AntiFlickerAndNoticeTheme.test.js`、`frontend/tests/audit-browser-smoke.mjs`：状态、首屏和浏览器行为测试。

## 7. 精修路线

1. **第一、二阶段：色彩与组件视觉统一**（本次）：建立暖黑旧设备底色、琥珀主信号、洗旧卡其/灰橄榄辅助色的调色板；让外观调谐图标由主题变量驱动，并统一公开导航、研究方向标签、论文行、资源卡片、主次按钮和状态细节。
2. **第三阶段：世界线氛围精修**：进一步核对环境光、低强度扫描线、短暂世界线切换动效和少量仪表标记。所有动画必须服务于状态反馈，不能遮挡正文或持续分散注意力。
3. **第四阶段：视觉回归**：在桌面与 390px 手机视口保存世界线皮肤首屏、研究方向和物理资源区截图，检查不同皮肤切换、窄屏导航、焦点样式、对比度、减少动态效果和交互兼容性。自动化测试通过不等于美术验收完成。

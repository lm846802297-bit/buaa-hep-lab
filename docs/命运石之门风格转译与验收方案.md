# 《命运石之门》视觉语言转译：课题组网站设计与验收

## 1. 目标与边界

目标是在北航粒子物理研究组网站中加入一套可选的“世界线终端（Worldline Console）”皮肤，并把《命运石之门》的视觉语言转译成适合科研网站的交互。它是可选皮肤，不替换 Quiet Research 默认风格，也不修改既有账号、科研资料、权限、API 或数据库逻辑。

实现只借鉴抽象的视觉语汇：冷蓝黑 CRT、青色磷光读数、电蓝世界线轨迹、品红异常色散、状态切换和手机/通知式反馈。不复制原作角色、标志、原画、截图、音乐或其他受版权保护的素材。

## 2. 研究依据

- [《STEINS;GATE》官方日文网站](https://steinsgate.jp/)将作品描述为以真实科学现象为骨架的科幻悬疑，并列出角色设计、道具设计和美术指导等制作分工。这支持从“科学设定 + 设备美术 + 信息呈现”提炼设计，而非仅模仿动漫角色。
- [《STEINS;GATE 0》官方游戏介绍](https://steinsgate0.jp/game/)明确描述手机应用的使用方式会影响故事发展，并介绍 Amadeus 与 RINE 消息交互。这为“操作应引起清楚的状态反馈”提供了交互层面的参考。
- [官方英文视觉小说网站](https://steins-gate.com/)也将分支剧情与手机操作列为核心特色。
- 视觉参考关键词：世界线变动仪/辉光数字、冷蓝黑底、青色 CRT 磷光、电蓝轨迹、品红色散、设备式边框与信号故障。以上为设计分析与抽象提炼，不表示原作所有界面都采用同一配色或同一实现。

## 3. 视觉令牌与色彩美术规范

### 3.1 美术方向

采用“**冷蓝黑底色 + 青色 CRT 磷光 + 电蓝世界线信号 + 品红异常干扰**”作为主视觉。目标不是一般的霓虹赛博朋克，而是尽可能高保真地重建《命运石之门》的冷色科学悬疑氛围：旧式显示器的蓝灰色层次、电子设备的扫描线、精密仪器的网格与读数、世界线变动时的色散和信号故障。

这是本项目基于公开参考做出的原创设计令牌，不宣称 HEX 值是原作官方色板。作品的不同版本、场景和界面本身存在色彩差异；应以选定的官方游戏/动画截图建立参考板，再逐项比对背景、文字、边框、光晕、图形和动态状态：
- [《STEINS;GATE》官方日文网站](https://steinsgate.jp/)
- [官方英文视觉小说网站](https://steins-gate.com/)
- [官方 Steam 游戏页面（含经典版游戏截图）](https://store.steampowered.com/app/412830/SteinsGate/)
- [官方《STEINS;GATE RE:BOOT》介绍](https://steinsgate.jp/reboot/en-us/)

**截图对照结论（设计转译，而非像素复制）：**经典版视觉小说公开截图中，实验室背景常见低饱和灰绿/橄榄灰与旧设备材质；手机硬件有克制的珊瑚红外壳，屏幕内则使用深色高对比信息行和精细终端图形。由此可见，原作的辨识度不只来自蓝色或霓虹，也来自“真实旧设备 + 叙事信息界面 + 科学仪器读数”的组合。本站继续以冷蓝黑、青色磷光和电蓝轨迹为主，但加入低频硬件灰、少量珊瑚红状态灯、带标签的仪器边框和更方正的面板；不复制角色、原画或具体 UI 素材，也不宣称这些颜色是原作官方色板。

### 3.3 配色与画面层级

- **冷色是底层，荧光色是信号**：背景与面板保持深蓝黑；青色和电蓝负责显示器读数、线框、数据可视化与交互状态。
- **品红只表达异常**：在世界线变动动画、短暂 glitch、警报和错误状态中出现；平时不大面积铺色。
- **保留 CRT 与旧设备的层次**：扫描线、轻微色偏、玻璃反射、显示器边缘暗角和微弱噪点共同构成质感，不只靠发光滤镜。
- **科研内容优先可读**：论文、公式、摘要和表格保持稳定背景；动态效果可以覆盖短暂的转场层，但不能长期遮挡正文或按钮。
- **避免做成通用赛博朋克模板**：不使用全屏随机霓虹、紫青渐变铺满所有卡片、无意义的数字雨；每种颜色和动画都对应可解释的 UI 状态。
- **引入旧设备质感而不是复古滤镜堆叠**：硬件灰与珊瑚红只用于监视器边框、状态灯和少量分隔线；正文、公式和图表依旧保持冷色高对比度。
- **技术背景是装饰层，不伪装成实验结果**：齿轮、圆规和世界线轨迹只承担氛围与导航感；图表明确标注为示意，不展示伪造的真实实验数值。

### 3.4 可读性基线

按 WCAG 相对亮度公式计算，以下值针对纯基底 `#07111D`，是设计阶段的近似参考：
- 主文字 `#E8F5FF`：17.11:1
- 次级文字 `#BED5E4`：12.49:1
- 辅助文字 `#88A6BC`：7.43:1
- 青色主信号 `#55E6F2`：12.64:1
- 电蓝辅助信号 `#83A9FF`：8.21:1

以上数值按 WCAG 相对亮度公式独立复算，针对纯基底 `#07111D`；半透明面板、渐变和图片背景还需要逐状态检查。正文、公式与论文元数据优先使用主/次级文字。错误、成功和选中状态不能只靠颜色区分，必须保留文字、图标或形状提示。

### 3.5 外观调谐图标的颜色契约

图标使用通用 `--theme-tuner-*` 变量，所有普通皮肤都从 `--text`、`--surface`、`--line` 和 `--accent` 派生颜色；因此切换皮肤后不需要为每个皮肤维护一份独立 SVG。

世界线终端只覆盖组件级变量：
- 外环：主文字与电蓝混合，形成冷色仪器刻度；
- 四向刻度：青色磷光；
- 中心星点：青色磷光；双节点：品红异常色；
- 按钮边界：青色与电蓝混合；
- 悬停状态：青色核心脉冲叠加电蓝环光；世界线皮肤下允许更鲜明的短时反馈。

图标不得在组件内写死颜色值。所有颜色变化必须来自当前主题变量，世界线终端的专项增强则由 `[data-color-scheme="worldline-console"]` 下的变量覆盖实现。

中文正文保持网站原有可读字体；只有 eyebrow、徽标、数字和终端式元信息使用等宽字体。

## 4. 交互规范

### 官网风格入口
- 首页将外观调谐图标放在主导航栏右侧；研究专题、团队和学术活动等公开子页面在右上方保留同一入口。
- 图标由环形轨道、四向刻度、双调节点与中心星点组成；颜色完全来自主题变量，世界线终端使用青色核心 + 电蓝轨道的专项配色。
- 点击图标打开轻量选择面板，显示当前风格并提供全部公开皮肤选项；点击外部区域或按 Escape 可关闭。
- 选择器不再长期占据右下角，避免遮挡页面内容；图标具有可访问名称、键盘焦点样式和移动端适配。
- 公开官网皮肤继续使用独立的 `labhub_public_color_scheme`，不影响协作空间的个人主题。

### 悬停
- 可交互卡片在桌面指针设备上出现青色/电蓝边框与辉光。
- 研究方向、论文、物理资源卡片可以配合青蓝能量边缘、扫描高光和短促位移；避免无意义的持续抖动。
- 粒子碰撞径迹在悬停时流动；全局环境粒子与世界线变动粒子爆发已纳入当前实现。
- 触屏设备不依赖 hover 才能访问信息。

### 点击
- 按钮与链接在按下时可以出现亮度脉冲、信号扩散或短促的扫描反馈，但必须保留原有点击行为。
- 所有反馈使用 CSS，不拦截点击、不更改链接目标、不延迟业务操作。

### 世界线变动
- 选择/退出世界线终端皮肤时，出现约 1.32 秒的扫描线、RGB 色散、故障切片、中心刻度盘、粒子爆发和“世界线变动” HUD。
- 在启用该皮肤时，公开页面或工作区路由切换会触发同类短动画。
- 动画层固定定位、`pointer-events: none`，不拦截用户操作。
- 动画可以更强烈：短暂全屏冷色闪变、RGB 色散、横向故障带、中心世界线刻度盘、向外爆发的粒子轨迹与 HUD 文本。效果必须在短时间内结束，不伪造实际世界线偏差率、实验读数或科研指标。

### 可访问性与性能
- 遵循 `prefers-reduced-motion: reduce`：禁用世界线切换动画和持续动效。
- 公开站点皮肤使用独立的 `labhub_public_color_scheme`；工作区偏好使用原有 `laborbit_color_scheme`。公开皮肤不得覆盖用户的工作区主题。
- 优先使用 CSS 与 Canvas 2D 实现粒子层，不引入 WebGL、视频、外部图片或音频依赖；控制粒子数量、监听页面可见性，并为减少动态效果偏好提供关闭路径。

## 5. 代码落点
- `frontend/src/composables/useThemeStyle.js`：注册 `worldline-console`，复用既有皮肤选择和持久化逻辑。
- `frontend/src/index.css`：调色板、终端细节、悬停/点击反馈与世界线过渡动画。
- `frontend/src/components/WorldlineEffects.vue`：监听皮肤与路由变化，驱动 Canvas 2D 环境粒子/爆发粒子、世界线变动 HUD，并处理减少动态效果、页面隐藏、尺寸变化和组件卸载。
- `frontend/src/components/PublicThemeSwitcher.vue`：以主题变量驱动的外观调谐图标和弹出式面板提供公开站点皮肤入口；首页嵌入导航栏，其他公开页面固定在右上角。
- `frontend/src/index.css`：定义通用 `--theme-tuner-*` 令牌、世界线终端的冷蓝黑/青色/电蓝/品红变量，以及 CRT 扫描线和信号层。
- `frontend/index.html`：首次绘制时识别新皮肤，避免刷新后先回退到其他配色再跳变。
- `frontend/src/composables/useThemeStyle.test.js`、`frontend/src/views/AntiFlickerAndNoticeTheme.test.js`、`frontend/tests/audit-browser-smoke.mjs`：状态、首屏和浏览器行为测试。

## 6. 分阶段实施

1. **阶段 A：高保真视觉基线**：已建立冷蓝黑底、青色磷光、电蓝轨迹和品红异常信号，并统一官网导航、研究方向、论文与资源卡片的终端细节；新增固定 SVG 技术底图，包含齿轮、制图圆规、轨道弧线、仪器读数框和注释标签。
2. **阶段 B：世界线动效**：已实现短时全屏世界线变动、RGB 色散、故障切片、扫描波、中心刻度盘和 HUD；主题切换、路由切换可触发，效果结束后页面恢复稳定。
3. **阶段 C：粒子与环境反馈**：已加入低频漂浮粒子、粒子连接线、鼠标附近微粒偏移/连线、点击脉冲和世界线切换时的径向粒子爆发；后续可继续丰富粒子碰撞轨迹与局部能量脉冲。
4. **阶段 D：视觉验收**：桌面/平板/手机截图对照；测试性能、减少动态效果、键盘操作、不同皮肤切换和所有原有业务交互。

## 8. 精修路线

1. **阶段 A：高保真视觉基线**：首轮截图已完成桌面与手机视口核对。对照经典版截图后，补强显示器边框、硬件材质、信息标签和方正面板；主题配色继续以冷蓝黑为主，少量硬件灰/珊瑚红仅作材质线索。
2. **阶段 B：世界线动效增强**：用单独的闪屏层控制全屏闪变，避免父级透明度把 HUD 一起淡化；在动效可读峰值截屏，检查中心刻度盘、故障切片、扫描波与 HUD 的层级。
3. **阶段 C/D：粒子特效与视觉回归**：继续核对环境粒子、鼠标附近微粒响应、点击脉冲与径向轨迹；在桌面、平板和 320/360/390px 手机视口检查排版、性能、可访问性、减少动态效果和原有交互。自动化测试通过不等于美术验收完成。

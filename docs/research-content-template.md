# 研究专题的审核与复现模板

公开新增专题须由课题组确定维护人，完成来源核对后再加入公开白名单。草稿保存在私有仓库；不自动从成员表、组会、邮箱、收藏或内部文献推荐生成公开内容。对于需要保留代码版本、输入参数、执行环境、输出文件和独立核查证据的符号/数值计算，另按 [计算记录数据模型与 API 契约](RESEARCH_RUN_RECORD_CONTRACT.md) 记录；该契约目前是设计提案，不表示相关 API 或数据库表已经实现。

## 基本信息

- 标题、作者/维护者、内容版本、最后核查日期。
- 状态：草稿 / 待学术审核 / 已核对来源 / 已完成独立复现 / 待更新。核对来源与独立复现分开。
- 相关方向、代表论文的 arXiv/DOI、代码 commit、数据和软件版本。

## 内容结构

1. **研究问题**：要检验的物理机制、与标准模型的关系。
2. **模型与约定**：拉格朗日量、粒子谱、参数定义、度规和归一化；说明 EFT 基底、尺度与重整化方案（如适用）。
3. **假设、近似与适用范围**：能标、参数范围、圈级、宇宙学历史、EFT 截断和理论不确定性。
4. **核心推导与计算**：中间步骤、量纲与对称性检查；软件仅作为计算工具，不替代证明。
5. **实验与统计**：原始实验论文、数据版本、能量与亮度、效率、似然/置信区间和系统误差。
6. **结论状态**：区分模型预言、实验灵敏度、实验允许/排除与实际观测；未评估区域明确标记。
7. **可复现材料**：脚本、环境、参数文件、随机种子、预期输出、容差和资源需求。
8. **独立验证**：解析极限、独立实现或数值基准，以及失败情况；未完成时不写“已验证”。
9. **参考与更新**：逐条说明文献支持的结论，记录修订与勘误。

## 建议建设队列

登录后的 `/learning` 已提供标准模型、振幅与截面、BSM 一致性、SMEFT/UV 匹配和 FeynCalc 五个学习初稿。维护者待课题组指定，学术审核尚未完成，不加入公开首页白名单。公式注明约定、来源与适用条件；Z₂ 势能条件给出配方推导，两体衰变示例附标准库 Python 实现及解析极限/独立求动量的一致性检查。FeynCalc 示例未在 Mathematica 中执行。

Higgs 门户、轻子规范相互作用、暗物质、相变、中微子、对撞机重解释与统计等研究专题仍需相应的学术审核和计算材料；本轮不发布参数扫描、实验排除图或论文独立复现结论。学习页是静态的非保密资料，不应存放未公开研究数据；路由登录和 noindex 不构成静态文件的保密措施。

## 代表论文维护

- 当前公开白名单为用户于 2026-10-20 确认的 16 篇；原始核对材料见 `audit/publication-candidates.json`。
- 每 3–6 个月建议人工核对出版状态、DOI、勘误和研究方向。维护人尚待课题组指定。
- 自动获取元数据只能形成草稿，不能直接替换公开白名单。课题组确认后更新 `frontend/src/content/lab.js`，通过目录、隐私、构建与浏览器检查再发布。
